# Simple Camera App 📸

## Project Overview

Simple Camera App is an Android application developed using Kotlin and Jetpack Compose. It allows users to capture photographs, view them inside the application, save them to the device gallery, and share them with other applications.

This project was developed as an Android application development assignment. Additional features were implemented to improve the user experience.

## Main Features

- **Open Camera:** Opens the device camera.
- **Capture Photo:** Captures photographs using the camera.
- **Display Photo:** Displays the captured photograph inside the application.
- **Share Photo:** Shares photographs using the Android system sharing interface.

## Additional Features

- **Delete Photo:** Removes the currently displayed photograph from the application.
- **Save to Gallery:** Saves captured photographs to the device gallery.
- **User-Friendly Interface:** Provides a simple interface with clearly labelled buttons.

## Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- Android Activity Result API
- Android FileProvider
- Android MediaStore API

## How to Use

1. Open the application.
2. Tap **Open Camera**.
3. Capture a photograph.
4. View the captured photograph in the application.
5. Use **Share Photo** to share it with other applications.
6. Use **Save to Gallery** to save it permanently.
7. Use **Delete Photo** to remove it from the application screen.
